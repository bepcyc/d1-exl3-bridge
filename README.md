# D1 ↔ ExLlamaV3 bridge

Experimental source-only projection/assembly tools and separately scoped AMD
compatibility patches. The implementation is proposed in a draft pull request
for owner review. No weights, photographs, datasets or turnkey GPU installer
are distributed.

The implementation distinguishes synthetic byte-preservation tests of the new
CLI from narrowly recorded historical AMD runtime results. LiquidAI-derived
source and patches retain the LFM Open License; they are not relicensed as
unrestricted open source.
